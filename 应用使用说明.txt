NBA 关注球员实时提醒 · 桌面应用版
========================================

【⚠️ 先看这条：必须整个文件夹一起用】
  本应用是「文件夹版」：NBAAlert.exe 必须和同目录下的 _internal 文件夹在一起！
  整个 NBAAlert 文件夹可以整体复制/移动到任何位置，但绝不能只单独拿走 exe。

  只复制一个 exe 双击，会报这个错：
      Failed to load Python DLL '...\_internal\python313.dll'
      LoadLibrary: 找不到指定的模块。
  这不是程序损坏，而是运行时依赖目录（_internal）没跟过来。
  从 GitHub Releases 下载时请下载 NBAAlert-Windows-x64.zip，并「解压整个文件夹」，
  不要在下载目录里只保存单个 NBAAlert.exe。

【启动】
  双击 NBAAlert.exe 即可。无需 WorkBuddy、无需 Python、无需命令行。
  启动后会自动打开默认浏览器到实时面板：http://127.0.0.1:8000
  程序常驻在屏幕右下角系统托盘，不占任务栏。

  放到桌面（只需做一次）：右键 NBAAlert.exe →「发送到」→「桌面快捷方式」，
  以后直接双击桌面图标启动（快捷方式指向本文件夹内的 exe，不要移动 exe 本身）。

【托盘图标右键菜单】
  打开实时面板        打开/回到浏览器面板
  演示模式            回放内置样本，不联网，用于快速验证全链路
  重启服务            修改配置后点这个生效
  打开应用目录        打开本文件夹
  查看运行日志        打开 data/app.log 排查问题
  退出                停止服务并关闭程序

  直接双击托盘图标 = 打开面板。
  重复双击 exe 不会开第二个实例，只会帮你打开面板。

【配置】（改完在托盘点「重启服务」）
  config.yaml
    watch.players        关注球员、中文别名、球衣号、订阅的事件类型
    vision.stream_url    直播流地址（m3u8 / 本地视频），留空则上场判定
                         自动回退到数据层换人事件，其余功能不受影响
    data_source.prefer   auto（推荐，nba_api 不通时自动降级 ESPN）
    app.poll_interval_sec  轮询间隔，默认 8 秒
  .env（由 .env.example 复制改名）
    WECOM_WEBHOOK        企业微信群机器人，填了就能收到手机提醒
    SERVERCHAN_KEY       Server酱，填了自动追加微信通道
    SMTP_USER/SMTP_PASS  邮件通道（QQ 邮箱用授权码）
  未配置凭证的通道自动停用，Windows 桌面气泡通知开箱即用。

【直播流地址怎么拿】
  聚合类直播站点的流地址多由 JS 动态生成，页面里没有明文 m3u8。
  方式一：浏览器打开直播间 → F12 → Network → 过滤 .m3u8 → 复制地址
  方式二：项目 tools/probe_stream.py（源码版）可尝试探测明文地址
  把地址填进 config.yaml 的 vision.stream_url，重启服务即可启用画面 OCR。
  提示：系统装了 ffmpeg 会优先用 ffmpeg 抽帧，没装则用 OpenCV 直读。

【注意】
  · 服务使用本机 127.0.0.1:8000，仅本机可访问，不对外暴露。
  · 首次轮询会预热（已有回合不推送），之后只推新产生的事件，不会刷屏。
  · 若 cdn.nba.com 被网络拦截，日志会出现「自动降级 ESPN」，属正常，功能不受影响。
  · 杀毒软件可能对未签名的 exe 报风险，选择允许即可；源码全部在项目里，可自行用
    python build_app.py 重新打包。
  · 日志与去重状态在 data/ 目录，删除 data/state.json 可重置推送记录。

【合规】

  加密或付费内容。公开数据接口请控制请求频率。仅供个人本地使用。
